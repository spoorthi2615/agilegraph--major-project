# AgileGraph
Graph-Learned Crypto-Agility Risk Scoring for Post-Quantum Migration

## Overview
AgileGraph translates cryptographic footprints into asset-level migration priorities using static analysis, active/passive scanning, and a Graph Neural Network (GNN).

## Structure
- `backend/`: FastAPI Python server, scanners, ML models.
- `frontend/`: React + Tailwind CSS dashboard.
- `docs/`: Architecture, Graph Schema, Ethics.

## Commands
Check `package.json` in `frontend` for React commands.
Check `backend/` for python requirements.
